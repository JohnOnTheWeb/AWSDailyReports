# Developer Experience and SDLC Transformation — Daily Digest (June 26, 2026)

## Key Developments

• **AWS Kiro Replaces Amazon Q Developer**: AWS officially transitioned from Amazon Q Developer to Kiro on May 7, 2026, with new signups closing May 15 and full support ending April 30, 2027. [Kiro introduces spec-driven development using EARS notation](https://www.techpillow.co/blog/amazon-kiro-aws-summit-nyc-spec-driven-2026), enforcing structured requirements before code generation to address ambiguous-brief failures common in agentic coding tools.

• **GitLab Research: AI Code Outpacing Control Systems**: GitLab's June 23, 2026 research reveals organizations are generating AI code faster than they can control it, coinciding with GitLab's recognition as a [Leader in the 2026 Gartner Magic Quadrant for DevSecOps Platforms](https://www.devopsdigest.com/gitlab-recognized-as-a-leader-in-the-gartner%C2%AE-magic-quadrant%E2%84%A2-for-devsecops-platforms-for-the-fourth). The company's Transcend event (June 10-11) showcased next-generation capabilities for the "agentic era."

• **Gartner Shifts Focus to "Agent Experience" (AX)**: Released in the first week of June 2026, [Gartner's latest report warns platform engineering teams](https://stonetusker.com/newsletters/) that their core target is shifting from optimizing for human developers to building Internal Developer Platforms for AI agents that autonomously execute backend deployment tasks.

• **AWS Context Intelligence Stack Launch**: AWS announced AWS Context and AWS Continuum at the [New York Summit on June 17, 2026](https://www.digitalapplied.com/blog/aws-summit-ny-2026-agentcore-continuum-context-agents). AWS Context automatically builds knowledge graphs from organizational data to provide AI agents with business context, while AWS Continuum automates security vulnerability lifecycle management.

• **MCP Ecosystem Reaches Production Scale**: The Model Context Protocol ecosystem has matured significantly, with [68% of production agent deployments adopting MCP](https://agentman.ai/blog/agent-skills-ecosystem-report-2026) or equivalent standardized tool layers according to Digital Applied's enterprise survey.

By automatically building knowledge graphs from existing organizational data, AWS Context positions itself as essential infrastructure for enterprise agentic workflows, potentially accelerating the adoption timeline for autonomous development practices.
